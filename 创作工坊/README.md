# 创作工坊 · Creator Workshop

把你的桌宠分享给全世界的三条通道（全部免费，无需自建任何服务）。

## 1️⃣ 分享你的宠物包

1. 把 `pets/你的宠物/` 文件夹压缩成 zip（选中**文件夹**压缩）；
2. 到 GitHub 仓库的 **Discussions → 分享你的宠物包** 发帖（模板见 [Discussions模板.md](Discussions模板.md)）；
3. zip 可直接拖进帖子（GitHub 附件 ≤25MB，宠物包一般只有几百 KB）；
4. 其他人下载后：右键宠物 → 导入宠物包 → 完成。

## 2️⃣ 皮肤包（轻量创作）

只想给缘缘换身衣服？参考 `pets/yuanyuan-newyear`（新春唐装版）和 `pets/yuanyuan-princess`（公主版）：
- 复制 `pets/yuanyuan/` 整个文件夹；
- 用你的图替换 `sprites/` 里对应状态的 PNG（文件名不变）；
- 改 `manifest.json` 的 `meta.name` 即可。

皮肤包分享方式同上——它们就是普通宠物包。

## 3️⃣ 从零开始

看 [../docs/创作指南.md](../docs/创作指南.md)——三条路径（改造/模板生成器/从零），10~30 分钟。
空白模板在 [空白模板/](空白模板/) 文件夹，复制进 `pets/` 填图就能用。

## 社区公约

- 素材须有权使用（自绘/自家宠物照片/CC0），不使用他人版权角色；
- `meta.license` 如实标注；
- 转载他人作品需注明出处并获授权。
