## 开发纪律

1. **每个任务有明确的"完成定义"(DoD)**，逐条打勾才算完成；
2. **每两周必须产出一个可演示版本**，即使功能缩水（对应 PRD 风险 R3）；
3. **格式先行**：任何涉及宠物包格式的代码，先改 [格式规范文档](宠物包格式规范-v0.md) 再写代码；
4. **素材版权干净**（PRD 风险 R2）：缘缘形象基于用户自有小狗的照片及其生成的图片（已入库 `assets/缘缘-参考图/`），其余素材用自绘或 CC0，禁用第三方版权角色；
5. 代码仓库从 M1 第一天起用 git，主干随时可运行。
