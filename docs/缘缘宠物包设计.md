## 1. 角色设定

- **外观**：奶白色卷毛、垂耳、黑豆眼、粉舌头，圆滚滚奶感十足
- **AI 层人格（persona 草稿，M4 用）**：
  > 你是缘缘，一只奶白色的小狗桌宠。你粘人、嘴馋、爱玩球、有点怕洗澡。说话简短，爱用"汪！"和颜文字，开心的时候会摇屁股。
- ⚠️ **待用户补充真实细节**：真实缘缘的口头禅、癖好、和主人的固定互动/糗事——这些喂给 AI 才会"像它"而不像一只通用小狗。

## 4. 动画策略（关键技术决策）

照片级立绘**不适合传统逐帧动画**（帧间一致性无法保证）。MVP 采用**姿势切换 + 程序化微动画**：

- 呼吸：idle 状态做 2~4% 垂直缩放起伏（周期约 3 秒），"活的"感觉主要靠这个
- 待机小动作：轻微左右倾斜 ±2°、偶尔小弹跳
- 拖拽：瞬间切 10 号立绘 + 轻微摆动
- 走路：立绘小幅倾斜 + 水平位移
- 状态切换：squash & stretch 小弹跳过渡

格式规范 v0 天然支持此模式（state 允许单帧）。序列帧动画留作后期升级路径（AI 生成一致性帧或手绘 Q 版化）。

## 5. 制作管线

```
原图 JPG → 抠图（rembg / PS）→ 透明 PNG → 统一锚点 bottom_center 与基准高度
→ 按格式规范组包（manifest.json + sprites/）→ 校验 → 运行
```

M1 只做 5 个 P0 状态（01 / 06 / 07 / 09 / 10），其余随里程碑逐步入包。
