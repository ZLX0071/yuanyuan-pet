## 三、关键技术事实（新会话必读）

| 事实 | 内容 |
|---|---|
| 技术栈 | Python 3.12 / PyQt6 / SQLite / pynput / PyInstaller；组装层 `src/yuanyuan/app.py`（约 700 行，所有接线在这） |
| AI 配置 | `data/config.json`（**gitignore**，含用户私人 Limix key，绝不入库）；模型 grok-4.7（用户指定）；月 200 万 token 护栏 |
| 启动 | `python main.py`；`启动缘缘.bat`（崩溃自启）；`--smoke N`（自动退出+截图）/`--fast-life X`/`--test-chat`/`--demo`（录屏编排）；便携版 dist/ |
| 验收 | scripts/check_*.py 共 8 套 81 项（loader/import/save/sense/m45/schedule/p0/p1），全部纯 Python 无 Qt |
| 性能 | 空闲 CPU 0.0%，内存 66-72MB |
| 安全钩子 | Mimosa 会拦：Bash 写源码（必须 Write/Edit 工具）、非字面量 SQL、未校验 URL（SSRF）——都已按规范处理，新代码注意 |
| 环境坑 | WScript COM 不收中文路径（用 8.3 短名 D1E0~1）；中文文件名 gh 上传会变 default（用 ASCII）；Windows runner 要 PYTHONUTF8=1；PyQt6 addAction(QAction) 返回 None |
| 常驻实例 | 我后台起的实例随会话死；用户日常用 bat 启动；单实例锁防重复 |
