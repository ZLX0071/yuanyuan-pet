# 缘缘桌宠 · 系统架构

| 项 | 内容 |
|---|---|
| 技术栈 | Python 3.12 / PyQt6 / SQLite / pynput / PyInstaller |
| 代码规模 | 引擎五层 + 8 个验收脚本，全部数据驱动 |

## 一、五层架构总览

```
┌─────────────────────────────────────────────────────────────────┐
│  内容层 content/                                                 │
│  宠物包 = 文件夹（manifest.json v1.0 冻结 + sprites/）            │
│  pack_loader（8 类人话校验）· pack_import（zip 导入/防滑/回滚）    │
│  ↕ 引擎只认格式，不内置任何具体宠物的逻辑（第一原则）               │
├─────────────────────────────────────────────────────────────────┤
│  AI 层 ai/                                                       │
│  provider（OpenAI 兼容 + SSRF 防护 + 月度 token 护栏）             │
│  notes（对话式记事：启发式闸门 → LLM 抽取 → 到期提醒）             │
│  ↕ 异步线程，无 Key 时全功能优雅降级                              │
├─────────────────────────────────────────────────────────────────┤
│  养成层 life/                                                     │
│  stats（饱食/心情/亲密度 + 离线补偿 + 成长阶段体型）                │
│  schedule（作息还原：每条每日一次/跨天重置）                        │
│  save（SQLite KV 线程安全 + 损坏自愈）                             │
├─────────────────────────────────────────────────────────────────┤
│  感知层 sense/                                                    │
│  hooks（pynput 键鼠监听，回调只入队）· events（5 类高层事件聚合）   │
│  reminders（喝水/久坐，全屏延后）· calendar（ICS 只读）            │
│  focus（番茄钟，引擎静默陪坐）                                     │
│  ↕ 全部仅内存计算，不落盘不上传（隐私铁律）                        │
├─────────────────────────────────────────────────────────────────┤
│  引擎层 engine/                                                   │
│  pet_window（透明置顶窗 + 拖拽 + 部位互动）                        │
│  animator（数据驱动状态机 + 3s 停留/30s 冷却防抖）                 │
│  physics（重力弹跳落地）· bubble（气泡 + 聊天输入条）              │
└─────────────────────────────────────────────────────────────────┘
        ↕ 数据流（全部单向、跨线程仅经队列）
用户输入 ──► pynput 线程 ──► raw_q ──► 4Hz sense_tick（主线程）
                                          │
              ┌───────────────────────────┼────────────────────────┐
              ▼                           ▼                        ▼
        SenseAggregator             ReminderScheduler         ScheduleEngine
        （typing_burst 等）          （喝水/久坐）              （作息触发）
              │                           │                        │
              └──────────► StateMachine（宠物包 behaviors 驱动）◄───┘
                                  │
                                  ▼
                          PetWindow（30fps 渲染 + 物理落点）
聊天输入 ──► 工作线程（provider.chat + notes 抽取）──► chat_q ──► 气泡
```

## 二、关键设计决策（为什么这样切）

| 决策 | 理由 |
|---|---|
| 素材/行为全数据驱动 | 引擎零"缘缘专属"代码；M6 创作生态的地基；改 JSON 即改性格 |
| 触发器防抖两级（全局 3s + 行为冷却 30s） | 修过 dozy↔sleep 高频抖动 bug；对齐 Shimeji/VPet 惯例 |
| 感知回调只入队 | pynput 线程绝不碰 Qt；跨线程只传不可变数据 |
| 按需从磁盘重建缩放帧 | 常驻内存 113→63MB（原始帧不驻留） |
| AI 可选 + provider 抽象 | 无 Key 全功能可用；换服务只改配置；成本护栏防失控 |
| zip 导入双重越界校验 | zip slip 防护；坏包自动回滚 |
| 单实例锁 + 日志 + 崩溃自启 | 稳定性三件套（M5） |

## 三、目录结构

```
缘缘桌宠/
├── main.py                 # 入口（支持 --pack/--smoke/--fast-life/--test-chat）
├── src/yuanyuan/
│   ├── engine/             # 引擎层（窗口/状态机/物理/气泡）
│   ├── sense/              # 感知层（钩子/事件/提醒/日历/专注）
│   ├── life/               # 养成层（数值/作息/存档）
│   ├── ai/                 # AI 层（provider/记事）
│   ├── content/            # 内容层（加载/导入）
│   ├── app.py              # 组装层（全部接线）
│   ├── settings_dialog.py  # 设置界面
│   └── autostart.py        # 开机自启
├── pets/                   # 宠物包 ×4（缘缘/示例团子/橘团子/长耳团）
├── scripts/                # 工具 + 验收脚本 ×8（check_*）
├── docs/                   # PRD/任务/规范/指南/竞品/架构…
└── data/                   # gitignore：存档/配置/日志
```

## 四、质量基建

| 机制 | 覆盖 |
|---|---|
| 验收脚本 | loader 8 / save 6 / sense 15 / m45 15 / schedule 9 / import 7 = **60 项** |
| 冒烟模式 | `--smoke N` 自动截图退出；`--fast-life` 时间倍速；`--test-chat` 对话链路 |
| 性能预算 | 空闲 CPU <1%（实测 0.0%）、内存 <150MB（实测 63-67MB） |
| 稳定性 | 按天日志 + 全局异常钩子 + 单实例锁 + 启动器崩溃自启 |
