## GitHub 发布步骤（你来操作，10 分钟）

1. GitHub 创建仓库 `yuanyuan-pet`（Public）；
2. 本地执行：`git remote add origin <你的仓库地址>` → `git push -u origin main`；
3. Releases → New release → tag `v1.0`，上传 `YuanyuanPet-portable.zip` + Release Notes（可从 README 进度区改写）；
4. 建议勾选：Issues（收集反馈）、 Discussions（作品分享区）。
