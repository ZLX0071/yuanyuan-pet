# 创作指南：不写代码，做出你自己的桌宠

这份指南面向**完全不会编程**的创作者。跟着做，10~30 分钟就能拥有一只属于你的桌宠。

## 三条创作路径（按难度递增）

| 路径 | 适合 | 耗时 |
|---|---|---|
| ① 改造现成包 | 想快速拥有"自家狗/猫"的形象 | 10 分钟 |
| ② 模板生成器 | 想要一个全新配色/耳型的小团子 | 5 分钟 |
| ③ 从零创作 | 想完全掌控外观和行为 | 1~3 小时 |

## 路径 ①：改造现成包（最推荐入门）

1. 打开缘缘文件夹里的 `pets/yuanyuan/`（或任意示例包），**整体复制一份**到 `pets/` 下，改成一个新文件夹名，比如 `my-pet/`；
2. 用你的图片替换 `sprites/` 里的 PNG——**保持文件名不变**（如 `idle_0.png`），图片建议透明背景、高度 384px 左右；
3. 打开 `manifest.json`（用记事本即可），改 `meta.name` 为你宠物的名字；
4. 缘缘托盘 → 切换宠物，你的桌宠就上场了。

**图片哪里来？** 用你拍的照片 + 任意"一键抠图"工具去掉背景，导出透明 PNG。

## 路径 ②：模板生成器

```bash
# 在缘缘文件夹打开命令行，执行：
.venv\Scripts\python scripts\make_sample_pack.py --name 团团 --color 250,200,150 --ears long --out tuantuan
```

参数说明：`--color` 身体颜色（R,G,B）、`--ears` 耳型（round 圆耳 / long 长耳 / none 无耳）、`--out` 输出文件夹名。生成后按路径①的方法替换图片、改 manifest 即可。

## 路径 ③：从零创作

### 必须了解的三件事

1. **一个宠物包 = 一个文件夹**：`manifest.json`（说明书）+ `sprites/`（图片）；
2. **状态（states）**：宠物的每个"姿势"是一个状态，如 idle 待机、sleep 睡觉——最少只需要 1 个状态、1 张图；
3. **行为（behaviors）**：什么情况下从一个状态切换到另一个——全部用"触发器"描述，不用写代码。

### 最小合法包（3 行配置起步）

```
my-pet/
├── manifest.json
└── sprites/
    └── idle/
        └── idle_0.png   ← 随便一张透明 PNG
```

```json
{
  "format_version": "1.0",
  "meta": { "name": "我的宠物", "license": "素材来源说明" },
  "states": { "idle": { "frames": "sprites/idle/idle_*.png" } }
}
```

这就完成了！然后逐步添加：更多状态 → 行为（触发器）→ 养成（life 段）→ AI 人格（personality 段）。全部字段说明见[宠物包格式规范](宠物包格式规范-v0.md)。

### 常见错误对照表（导入时报错看这里）

| 报错 | 原因 | 解法 |
|---|---|---|
| 缺少 manifest.json | zip 里没有说明书 | 选中**文件夹**压缩（zip 里要有文件夹） |
| 找不到任何帧图片 | frames 通配符和实际文件名对不上 | 检查文件名和路径拼写 |
| 行为跳转到未定义的状态 | behaviors 里 to 了没定义的状态名 | 先在 states 里定义它 |
| 不是合法 JSON | 少逗号/引号/括号 | 用 jsonlint.com 之类工具检查 |

## 分享你的作品

1. 把你的宠物包文件夹压缩成 zip；
2. 发给朋友——对方右键缘缘 → "导入宠物包…" 即可安装；
3. 发布到社区（M6 开放后）请注明素材许可（`meta.license`）。

## 创作者公约

- 素材必须是你有权使用的（自绘/自己宠物照片/CC0）；
- 不要使用他人作品的角色形象；
- `meta.license` 如实填写。
