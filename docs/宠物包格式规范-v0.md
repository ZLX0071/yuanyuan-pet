# 宠物包格式规范 v0（草案）

| 项 | 内容 |
|---|---|
| 状态 | 🚧 v0 草案：M1 开发期间允许破坏性修改 |
| 冻结承诺 | v1.0 起（M6）向后兼容，之后只能加不能改 |
| 读者 | 开发者（引擎实现）；未来：创作者（照此做宠物包） |

> **为什么这份文档是项目第一优先级：** 引擎只认格式、不内置任何具体宠物的逻辑（PRD §7.3 关键决策）。这份规范就是引擎和创作者之间的合同。

## 1. 宠物包是什么

一个宠物包 = **一个文件夹**，里面放图片帧 + 一个 `manifest.json`。引擎加载这个文件夹，宠物就有了外观和性格。使用者拿到文件夹（或 zip）放进 `pets/` 目录即可使用。

```
pets/mochi-cat/
├── manifest.json          # 唯一必需的描述文件
└── sprites/               # 图片帧（PNG，透明背景）
    ├── idle/              # 按状态分目录
    │   ├── idle_0.png
    │   └── idle_1.png
    ├── walk/
    ├── drag/
    ├── sleep/
    └── eat/
```

## 2. manifest.json 结构（v0）

```jsonc
{
  "format_version": "0.1",
  "meta": {
    "name": "麻薯猫",
    "author": "you",
    "version": "1.0.0",
    "description": "一只软软的像素猫",
    "license": "CC0"                    // 必填：素材来源与许可（PRD 风险 R2）
  },
  "display": {
    "scale": 1.0,                       // 相对基准高度(96px)的缩放
    "anchor": "bottom_center"           // 落地锚点
  },
  "default_state": "idle",              // 有时长的行为结束后回到的状态（缺省 "idle"）
  "startup_state": "excited",           // 可选：启动时先进入的状态（开机问候）
  "startup_duration_s": 2.5,            // 上述状态持续秒数，之后回 default_state
  // 状态 = 一段可播放的动画
  "states": {
    "idle": {
      "frames": "sprites/idle/idle_*.png",   // 通配符按文件名排序
      "fps": 4,
      "loop": true
    },
    "walk": {
      "frames": "sprites/walk/walk_*.png",
      "fps": 8,
      "loop": true,
      "movement": { "speed": 40 }            // px/s，播放时水平位移
    },
    "sleep": { "frames": "sprites/sleep/sleep_*.png", "fps": 1, "loop": true }
  },
  // 行为 = 状态机怎么走 + 被什么触发
  "behaviors": [
    { "id": "wander",
      "from": "idle", "to": "walk",
      "trigger": { "type": "random", "every_s": [20, 90] },   // 20~90 秒随机触发
      "duration_s": [3, 8],                                    // 走 3~8 秒回 idle
      "interruptible": true },

    { "id": "picked_up",
      "from": "*", "to": "drag",                              // "*" = 任何状态
      "trigger": { "type": "drag_start" } },

    { "id": "nap",
      "from": "idle", "to": "sleep",
      "trigger": { "type": "idle_time", "s": 300 },            // 闲置 5 分钟睡觉
      "wake": { "trigger": { "type": "click" } } },

    { "id": "react_typing",                                   // 互动反馈示例（M3 用）
      "from": "idle", "to": "alert",
      "trigger": { "type": "sense", "event": "typing_burst" } }
  ],
  // 养成联动（M2 用）：数值门槛改变行为
  "life": {
    "stats": ["hunger", "mood", "intimacy"],
    "rules": [
      { "when": { "hunger": "< 30" },
        "effect": { "force_behavior": "hungry", "bubble": "我饿了…" } }
    ]
  },
  // AI 人格（M4 用）：喂给 LLM 的性格设定
  "personality": {
    "prompt": "你是麻薯，一只慵懒但粘人的像素猫。说话简短、爱用颜文字。",
    "proactive": { "max_per_day": 5 }     // 主动说话上限（T4.5）
  }
}
```

## 3. 触发器 (trigger) 类型清单 — v0

| type | 参数 | 引入版本 | 说明 |
|---|---|---|---|
| `random` | `every_s: [min, max]` | v0 | 随机间隔触发 |
| `idle_time` | `s` | v0 | 持续闲置 N 秒 |
| `click` / `double_click` | — | v0 | 点击宠物 |
| `drag_start` / `drag_end` | — | v0 | 拖拽开始/结束 |
| `sense` | `event`（M3 定义枚举：`typing_burst` `long_idle` `app_switch`…） | v0（M3 实现） | 感知事件 |
| `stat` | `stat` + 条件 | v0（M2 实现） | 数值越线 |

> **v0 实现约定（2026-10-24，随 M1 开发确定）**：① 行为的 `duration_s` 到期后进入 `default_state`；② 唤醒用通用事件行为即可（如 `{"from": ["sleep"], "to": "idle", "trigger": {"type": "click"}}`），`wake` 字段解析但引擎不依赖；③ `sense`/`stat` 触发器在 M2/M3 实现前被解析但保持惰性。

## 4. 校验规则（加载器必须实现）

1. `manifest.json` 缺失或 JSON 解析失败 → 拒载，报"manifest 缺失/格式错误：\<详情\>"；
2. `states.*.frames` 通配符匹配不到任何文件 → 拒载并报缺哪个状态；
3. `behaviors.*.from/to` 引用了不存在的状态 → 拒载；
4. `meta.license` 缺失 → 警告但可加载（v1 起改为拒载）；
5. 图片尺寸不一致 → 警告（v1 起按 anchor 对齐，不再警告）。

## 5. 设计原则（改格式前必读）

1. **创作者不用编程**：一切行为只用"状态 + 触发器 + 规则"表达；如果某行为表达不了，优先扩展触发器类型，而不是让创作者写代码；
2. **渐进复杂度**：最小合法包 = meta + 1 个状态 3 行配置；高级功能（life/personality）全部可选；
3. **性能预算内**：帧图单张 ≤ 512×512px（照片级立绘裁剪到高 384px 左右最佳），单状态 ≤ 60 帧（加载器校验，超限为警告）；
4. **本地与隐私**：格式永远不包含网络请求类触发器；`sense` 事件只在本地处理。
