## 竞品拆解：DeepSeek「大肥鱼」桌宠（2026-10-25）

**是什么**：DeepSeek 社区吉祥物"鲸鱼娘·大肥鱼"的桌宠，以 [DSH（DeepSeek Harness，官方开源"一切皆插件"Agent 桌面框架）](https://www.deepseek.com/zh/harness)插件形态引爆：[官方讨论区热帖](https://github.com/deepseek-ai/deepseek-harness/discussions/2026)附完整创作物料（提示词+图片），衍生多个独立实现（[ds-local-pet 本地优先](https://github.com/QCYTSN/ds-local-pet)、[PySide6 版](https://github.com/RYANFFY/deepseek-dafeiyu-pet)、[Electron AI 对话版](https://zhuanlan.zhihu.com/p/2073731192403267630)），B 站有安装教程，还有"多只大肥鱼同时干活"玩法。

**火因拆解**：① 借 DeepSeek 官方框架的流量池分发（官方讨论区）；② 梗文化（吉祥物）+ 情绪极简定位（"不轮询不插桩，就一件事——陪你"）；③ **官方提供创作物料 → 人人可按模板做自己的桌宠**（UGC 乘数）；④ 一键安装、离线、免费；⑤ 低成本高萌感细节（不同身体部位鼠标互动反应不同）。

**决策（2026-10-25）**：
- ❌ **不做 DSH 插件**：DSH 用户群是开发者/编程场景，与缘缘"陪伴+助理"大众定位错位；塞进别人生态受插件形态限制，且缘缘引擎本就是独立完整 App；
- ❌ **不做手机 App**（维持 V2）：记录需求先在桌面端用"今天的瞬间"轻记录（X4）满足；
- ✅ **抄它的生态打法而非形态**：DSH 官方"物料模板 → 人人做桌宠"正是缘缘 M6 的设计（宠物包格式 + 创作教程 + 模板生成器）——缘缘的开源发布（GitHub + B 站）就是自己的"大肥鱼时刻"；
- ✅ **吸收部位互动**（低成本高萌感）：鼠标命中身体不同部位（头/肚子/尾巴）触发不同反应，加入待办。

## 原则（新增功能全部遵守）

1. 感知/记录类功能**默认最小化**，敏感项（剪贴板/屏幕）显式 opt-in 且有总开关；
2. AI 主动行为全部过"打扰度"预算（每天上限，静默模式一刀切）；
3. API 成本每功能单独核算，超预算自动降级为本地规则；
4. 一切新能力进"宠物包格式"或配置，不硬编码进引擎。

## 习性学习（2026-10-25，源自外部产品会议的启发，功能池新增）

**背景**：一份独立产品会议纪要提出"生前记录 → AI 学习习性 → 死后疗愈"的宠物数字复刻方案（多模态记录、作息还原、自主行为、自然记录不打卡）。与我们独立趋同的三个判断：桌宠是低成本切入点、养成/习性还原 > 纯对话、砍硬件聚焦虚拟。产品定位差异：他们是"复刻你家真实宠物"，缘缘是"通用桌宠人格"——同一条技术栈的两个产品位。

**可吸收进缘缘的（按依赖排序）**：

| # | 功能 | 说明 | 依赖 |
|---|---|---|---|
| X1 | 作息还原（第一层，零 AI 成本） | 用户在设置里"教"缘缘作息（起床/吃饭/下班/睡觉时间），缘缘按作息自主生活——"越用越像你/你家宠物"的第一步；行为规则引擎现成 | M5 完成 ✓ |
| X2 | 标志性行为库 | 用户自定义 2~3 个"它才会做的事"（如"叼拖鞋"），绑定到行为规则/宠物包 | X1 |
| X3 | 语音记录条目 | 记事功能支持语音输入（本地 Whisper 转写），验证"语音>打字"的记录需求 | V2 语音 |
| X4 | "今天的瞬间"轻记录 | 一图一句话的日常记录（不设任务、不打卡），融入养成记忆 | M4.5 记事 ✓ |
| X5 | 习性学习（第二层，AI） | 从记录数据里统计作息/行为模式自动填充 X1 作息表；进阶（视频理解）为深水区，不先做 | X1 + 记录积累 |

**伦理与心理设计原则（若走"逝去宠物疗愈"方向必须遵守，且这些原则同样适用于缘缘）**：
1. 明示"这是 AI，不是它"——预期管理是底线；
2. 数据主权与"遗托"：宠物/记录数据归用户，服务停止时数据可导出——绝不允许"停订阅=二次失去"的商业模式；
3. 哀伤支持设计：对丧宠用户应有阶段设计与专业资源引导，AI 说错话 = 二次伤害，需要响应边界；
4. "像"的验证：以主人主观盲评为准（作息/标志行为/声音三层），不做生成式视频复刻的深水区起步。
