## 目录结构（对应 PRD 五层架构）

```
src/yuanyuan/
├── engine/   # 引擎层：透明窗口、动画状态机、物理
├── sense/    # 感知层：键鼠钩子、系统事件
├── life/     # 养成层：数值、演化、存档
├── ai/       # AI 层：对话、记忆、性格
└── content/  # 内容层：宠物包加载与校验
pets/         # 宠物包（缘缘包在这里）
scripts/      # PoC 与工具脚本
```

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts/poc_transparent_window.py   # T1.2 透明窗口 PoC
```

```bash
python main.py --smoke 15           # 冒烟测试：15 秒后自动退出并截图
```
